ReRev Labs / The Lab
Youth creative-technology & hardware club

A program from ReRev Labs, for Wearable Tech Ventures

From idea to a working device — in one sitting.

The Lab is a creative-technology club that makes it easy for kids to build real hardware: cyberdecks, Raspberry Pi projects, and smart mirrors. A student starts with an idea and leaves the session holding the thing they made.

build: cyberdeck / display module status: prototyped

What students build

Three project lines students can move through, each ending in a physical object they keep.

Cyberdecks

Handheld, hacker-style computers students wire and case themselves — screen, keyboard, and a small board doing the thinking.

Raspberry Pi projects

Small physical-computing builds — sensors, lights, motors — driven by code students write and test themselves.

Smart mirrors

A two-way mirror with a hidden display behind it, showing whatever a student's code decides to surface.

Why this works now

AI coding tools have made hardware genuinely teachable at this age — the gap between "I have an idea" and "I have working code for it" has closed enough that a student can cross it in a single session.

The Lab is early: a program built behind the scenes for a while, now moving into real conversations with partners.

Already running

This fall, ReRev Labs is running a startup club with Breakthrough Birmingham for their high school students, with the semester ending in a pitch competition. The Lab is the next program alongside it.

Building this with partners

Jade Lockard connected us because of Wearable Tech Ventures' social impact programming. As The Lab takes shape, I'd like to talk about where it could fit.
