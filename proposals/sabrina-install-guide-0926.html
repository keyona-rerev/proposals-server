Chief of Staff Agent

Sabrina — Install & Test Guide

Cowork + Apps Script + Google Workspace. Use this for every new install. Gmail-based accounts only.

Overview

What Sabrina Does

Sabrina is a chief-of-staff agent. She watches for work you assign her, does the part of it she can do on her own, and comes back to you only for the part that needs a human decision.

In practice, she does this:

  • Takes work in through your calendar, your inbox, or a direct email. Put an event on your Task Calendar, label an email, or email her alias — any of the three starts a job.
  • Does the doable part first. She drafts the email, pulls the context, or works the task before asking you anything.
  • Emails you only the open decisions. One short email per job. No digests, no long reports.
  • Takes your reply like she's a colleague. Reply in plain language and she picks the job back up from there.
  • Follows up until the job is actually done. She checks back every day or two on anything still open, and she verifies completion herself — she does not take her own word for it.
  • Reads meeting transcripts for your action items. She pulls out only the next steps that belong to you and works those the same way.
What this page is not: a list of function names from the code. That's intentional — the rest of this guide covers what's actually being installed and how. This page is only "what does it do for the person using it."
Stack & Order

The Stack

PieceJob it does
Job Board (Google Sheet)The only memory the system has. Every job, its status, and its history live here as rows.
Google Apps ScriptWatches the calendar and Gmail, writes new job rows, and sends every outgoing email from the agent's own address.
GmailBoth the trigger surface (labels, direct email) and the reply surface. The account must be a Gmail/Google Workspace account — not Microsoft 365.
Google CalendarA dedicated Task Calendar, separate from the real-events calendar, is the third trigger surface.
CoworkThe worker. On a schedule, it claims a queued job row, does the work, and writes the result back to the row.

Why the Order Matters

Do the Sheet before the Apps Script. In that order:

  1. Copy the Job Board Sheet first, so you have its real Sheet ID.
  2. Copy the Apps Script project second, and set it up pointing at that real ID from the start.
Why: the script needs the Sheet's real ID to work at all. Doing the script first means setting a placeholder, then coming back to fix it — that's exactly how the column-mismatch and wrong-ID bugs happened on a past install. Sheet first removes the placeholder step entirely.

Full step-by-step order is on the Install page. High-level shape:

  1. Job Board Sheet
  2. Apps Script project (configured with the real Sheet ID and Calendar ID)
  3. Gmail labels and filters
  4. Cowork skill and scheduled task
  5. Test end to end
Step 3 of 4

Installation

Assumes the Job Board Sheet template and Apps Script project template are already attached/shared for this install.

  1. Create the send-as alias (agent@domain.com) on the Google account. Confirm it in Gmail → Settings → Accounts → Send mail as.
    📸Screenshot here: the Gmail "Accounts" tab with the new alias listed under Send mail as.
  2. Copy the Job Board Sheet template. Rename it for the new install.
  3. Copy the Apps Script project template into the account.
    📸Screenshot here: the Apps Script project list showing the copied project.
  4. Create Gmail labels: the Agent trigger label, plus one label per lane/client.
    📸Screenshot here: Gmail label list with the new labels visible.
  5. Authorize the Apps Script project with the Google account (OAuth).
    📸Screenshot here: the OAuth consent screen and the "Allow" step.
  6. In the copied script, set the identifiers for this install: the new Job Board Sheet ID, the Task Calendar ID, and the agent alias.
    This step is under review — moving these identifiers out of the code and into Script Properties, so this step no longer means editing code. Guide will update when that ships.

  7. Add every sending address that should be able to start a job to the allowlist.
  8. For any inbox that will not get its own Apps Script project, add a Gmail filter on that account (To: agent's address → apply label Agent).

Step 4 of 4

Run the Test

Check off each item as you complete it. Don't move to the next until the current one is confirmed.

0 of 6 confirmed
  • Run selfTest in Apps Script. Confirm it sends a real email from the agent alias.
  • Run a Cowork smoke test. Confirm all three: read a sheet cell, write a sheet cell, state one fact only account memory would know.
  • Create one real [Agent] calendar event. Confirm the watcher writes a queued row.
  • Confirm Cowork claims and works the row on its next scheduled run.
  • Confirm Apps Script delivers the resulting email from the agent alias.
  • Test the inbound path on the agent alias separately from send-as. Confirm the alias can receive mail, not just send it.
