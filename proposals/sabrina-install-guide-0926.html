Chief of Staff Agent

Sabrina — Install & Test Guide

Cowork + Apps Script + Google Workspace. Use this for every new install.

Installation
  1. Create the send-as alias (agent@domain.com) on the Google account. Confirm it in Gmail → Settings → Accounts → Send mail as.
  2. Copy the Job Board Sheet template. Rename it for the new install.
  3. Copy the Apps Script project template into the account.
  4. Create Gmail labels: the Agent trigger label, plus one label per lane/client.
  5. Authorize the Apps Script project with the Google account (OAuth).
  6. In the copied script, set the identifiers for this install: the new Job Board Sheet ID, the Task Calendar ID, and the agent alias.
  7. Add every sending address that should be able to start a job to the allowlist.
  8. For any inbox that will not get its own Apps Script project, add a Gmail filter on that account (To: agent's address → apply label Agent).
  9. Copy the Cowork runtime skill template. Update the identifiers (Sheet ID, Calendar ID) for this install.
  10. Upload the skill as a zip via Settings → Customize → Skills.
  11. Create the Cowork scheduled task. Set it Active, hourly cadence, pointed at the skill.
Testing
  1. Run selfTest in Apps Script. Confirm it sends a real email from the agent alias.
  2. Run a Cowork smoke test. Confirm all three: read a sheet cell, write a sheet cell, state one fact only account memory would know.
  3. Create one real [Agent] calendar event. Confirm the watcher writes a queued row.
  4. Confirm Cowork claims and works the row on its next scheduled run.
  5. Confirm Apps Script delivers the resulting email from the agent alias.
  6. Test the inbound path on the agent alias separately from send-as. Confirm the alias can receive mail, not just send it.
